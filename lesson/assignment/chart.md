# 車両制御フローチャート（修正版）

## 車両制御フローチャート（メインループ）

```mermaid
flowchart TD
    A(loop開始) --> B{is_running}
    B -->|No| H[ブレーキ]
    B -->|Yes| C{センサが一定時間更新なし}
    C -->|Yes| Z[is_running = false]
    C -->|No| D{交差点通過後の保持時間超過}
    D -->|Yes| Z
    D -->|No| E{走行時間上限に到達}
    E -->|Yes| Z
    E -->|No| F{is_running}
    Z --> F
    F -->|No| H
    F -->|Yes| G{交差点に突入している}
    G -->|Yes| I[交差点突入時間を記録]
    G -->|No| J[[自分の到着時間を計算]]
    I --> J
    J --> K{相手の到着情報が有効}
    K -->|Yes| L[[衝突回避制御で目標速度を更新]]
    K -->|No| M[[現在速度を取得]]
    L --> M
    M --> N[PWMを計算]
    N --> P[モータ制御]
    P --> Q[自身の情報をブロードキャスト]
    Q --> O(ループ終了)
    H --> O
```

3つの停止条件は独立したOR条件で、いずれか1つが成立した時点で以降の判定を行わずis_runningをfalseにします。停止指令（Eの判定）はここには存在せず、FINISHパケット受信時にコールバック側で非同期にis_runningがfalseになるだけです。

## 自分の到着時刻を計算するサブシステム

```mermaid
flowchart TD
    A(呼び出し: 突入 or 退出時間を計算) --> B[現在位置を計算]
    B --> C{現在速度が0以下 or 速度誤差が閾値超}
    C -->|Yes| D(無効時間を返す)
    C -->|No| E[対象地点までの残り距離を計算]
    E --> F{残り距離が0以下}
    F -->|Yes| G(0を返す)
    F -->|No| H[到達までの時間を計算]
    H --> I(到達時間を返す)
    D-->END(終了)
    G-->END
    I-->END
```

この関数は実際には2回呼ばれます。突入時間(`predict_time_to_intersection_us`)は交差点入口までの距離、退出時間(`predict_time_to_exit_intersection_us`)は入口＋出口距離＋車体長までの距離で計算するため、Eの「対象地点」が呼び出しごとに異なります。

## 衝突回避制御で目標速度を更新

```mermaid
flowchart TD
    A(呼び出し) --> B{相手の情報が無効}
    B -->|Yes| C(目標速度をそのまま返す)
    B -->|No| D{相手がすでに交差点を通過}
    D -->|Yes| E(初期速度を返す)
    D -->|No| F[相手の突入時間を補正]
    F --> G[相手の退出時間を補正]
    G --> H[交差点までの残り距離を計算]
    H --> I{すでに交差点を通過}
    I -->|Yes| C
    I -->|No| J{現在速度が0以下}
    J -->|Yes| C
    J -->|No| K{自分の到達予測が無効}
    K -->|Yes| C
    K -->|No| L{意図的に衝突させる設定か}
    L -->|Yes| M[到着目標時間を相手の突入時間に合わせる]
    L -->|No| N{十分な余裕がある}
    N -->|Yes| C
    N -->|No| O{自分が相手より先に突入する}
    O -->|Yes| P[到着目標時間を相手の突入より早くする]
    O -->|No| Q[到着目標時間を相手の退出より後にする]
    M --> R{到着目標時間が0以下}
    P --> R
    Q --> R
    R -->|Yes| C
    R -->|No| S[必要速度を算出]
    S --> T[速度を指定範囲内に制限]
    T --> U[相手の情報を破棄]
    U --> V(新たな目標速度を返す)
    C-->END(終了)
    V-->END
    E-->END
```

「目標速度をそのまま返す」への合流点を複数箇所（B, I, J, K, N, R）すべて明示し、Cに統一しました。Lは「衝突回避するか」ではなく「意図的に衝突させる設定か」という意味です。

## 現在速度を取得

```mermaid
flowchart TD
    A(呼び出し) --> B[[センサ反応間隔の近傍平均を取得]]
    B --> C[最後にセンサが反応してからの時間を計算]
    C --> D[近傍平均と経過時間のうち大きい方を有効間隔として採用]
    D --> E{有効間隔が0または無効}
    E -->|Yes| F(0を返す)
    E -->|No| G(現在速度を返す)
    F-->END(終了)
    G-->END
```

無効時間ではなく「0（停止扱い）」を返す点を修正しています。
