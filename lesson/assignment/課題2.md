# PIDコントローラ実装課題 教員向け説明書

## 1. 課題概要

本課題では、現在速度と目標速度からPWM出力を求める、**1フレーム単位の離散時間PIDコントローラ**を学生に設計・実装させる。

対象となる関数は以下のとおり。

```cpp
uint8_t calculate_pid_pwm(
    int32_t current_speed_cm_s,
    int32_t target_speed_cm_s
);
```

入力値は速度 `[cm/s]`、出力値はPWM値である。

---

## 2. 学生に要求する実装

以下の条件を満たすPID制御を実装させる。

* PIDゲインとして `pid_kp`、`pid_ki`、`pid_kd` を使用する。
* 目標速度と現在速度から偏差を求める。
* 比例項・積分項・微分項を用いてPWM出力を計算する。
* 積分値を `pid_integral` に累積する。
* `pid_integral` は `-PID_MAX_INTEGRAL` ～ `PID_MAX_INTEGRAL` の範囲に制限する。
* 微分項の計算には、前フレームの偏差を保持する `pid_previous_error` を使用する。
* PWM出力を `MIN_PWM` ～ `MAX_PWM` の範囲に制限する。
* 最終的なPWM値を `uint8_t` で返す。

---

## 3. フレーム間で保持する状態

PID制御では、現在のフレームだけでなく過去の値を使用する。

```cpp
float pid_integral = 0.0F;
float pid_previous_error = 0.0F;
```

* `pid_integral`：これまでの偏差の累積値
* `pid_previous_error`：前フレームの偏差

これらはフレームをまたいで値を保持する必要がある。

---

## 4. 課題の位置づけ

本課題では、学生が設計したPIDコントローラを実際の実験に使用し、制御結果を確認・評価する。

したがって、**唯一の模範解答を求める課題ではない**。

指定された条件を満たすPIDコントローラを各自で設計し、その設計によって得られた実験結果を評価させることを目的とする。

---

## 5. 教員用プログラムについて

教員が用意したPIDコントローラの実装例は、**動作確認および実験環境の確認を目的としたプログラム**である。

これは学生に対する模範解答ではなく、課題の正解として扱わない。

学生には設計条件を提示し、自らPIDコントローラを設計・実装させた上で、その制御性能を実験によって確認させる。
