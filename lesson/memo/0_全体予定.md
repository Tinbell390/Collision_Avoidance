# 第3回：コントローラ設計・車両走行実験

* 実験車両を実際に走行させる
* 実験結果から適切なゲインを設計する

## 授業内容

第3回の実験は、以下の2段階に分けて行う。

### 1. コントローラ関数の設計

車両制御に使用するコントローラ関数を設計する。

設計対象のファイル：


ただし、**教員用プロジェクトフォルダ**では以下のファイルを使用する。

# 第4回：衝突回避実験

## 目的

* 交差点コースを構築する
* 2台の実験車両を用いて衝突実験を行う
* 車車間通信を用いた衝突回避制御を実験する
* 衝突回避の効果を評価する

## 授業内容

### 1. 交差点コースの作成

2台の実験車両が交差する交差点コースを作成する。

### 2. 実験パラメータの設定

コースに合わせて、以下の設定を変更する。

```text
project/include/config/hpp
```

変更可能なパラメータは以下の通り。

```cpp
constexpr int32_t DIST_TO_INTERSECTION_ENTRY_MM = 2500;
// 交差点進入位置までの距離（ミリメートル）

constexpr int32_t DIST_TO_INTERSECTION_EXIT_MM = 200;
// 交差点退出位置までの距離（ミリメートル）

constexpr uint8_t SPEED_THRESHOLD_CM_S = 5;
// 到着時間を計算しても良い速度閾値（センチメートル/秒）

constexpr float PID_KP_DEFAULT = 0.0F;
// 比例ゲインのデフォルト値

constexpr float PID_KI_DEFAULT = 0.0F;
// 積分ゲインのデフォルト値

constexpr float PID_KD_DEFAULT = 0.0F;
// 微分ゲインのデフォルト値

constexpr uint32_t TIME_MARGIN_US = 500000;
// 交差時間のマージン（マイクロ秒）
```

また、第3回で設計した**各ゲインの値に変更する**。

### 3. 衝突実験

まず、**衝突制御を行わない状態**で実験車両を走行させる。

2台の車両が交差点で衝突することを確認する。

### 4. 衝突回避実験

次に、車車間通信を利用した**衝突回避制御**を有効にして実験を行う。

2台の実験車両を走行させ、交差点において衝突を回避できることを確認する。

### 5. 実験結果の評価

以下の観点から実験結果を評価する。

* 衝突制御時に実際に衝突が発生したか
* 衝突回避制御によって衝突を回避できたか
* 車両の走行状態が適切であったか
* 車車間通信が衝突回避にどのように利用されたか
* 通信・制御による遅延や誤差が結果に与える影響

# 任意実験：モータ評価実験

第3回または第4回の授業で時間に余裕がある場合に実施する。

## 目的

複数種類のモータについて走行性能を比較し、今回の実験に適したモータを考察する。

## 実験内容

1. 複数種類のモータから使用するモータを選択する
2. 選択したモータを実験車両に換装する
3. 車両を走行させる
4. モータに合わせてゲインを調整する
5. 走行データを取得する
6. モータごとの走行性能を比較する

## 評価・考察

次の考察課題について考察する

- ESP-NOWがIPアドレスではなくMACアドレスによって通信相手を識別している理由を考察せよ．また，IPアドレスを用いた通信と比較した場合のESP-NOWの利点と欠点について述べよ
- ESP-NOWにおいて通信遅延やパケットロスが発生した場合，相手車両の位置情報が実際の状態より古くなる．これによって衝突回避判断にどのようなリスクが生じるか考察せよ
- 各モータの特性を類推し，本実験に最も適したモータについて考察する．追加実験を行わなかった場合には不要である
