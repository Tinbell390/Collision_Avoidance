# 5.4 衝突回避実験

## 1. 変更してもよい変数

### `include/config.hpp` を設定

#### ① 交差点に関する距離

```cpp
DIST_TO_INTERSECTION_ENTRY_MM = 2500;
DIST_TO_INTERSECTION_EXIT_MM  = 200;
```

* `DIST_TO_INTERSECTION_ENTRY_MM`

  * 交差点進入位置までの距離 [mm]
* `DIST_TO_INTERSECTION_EXIT_MM`

  * 交差点退出位置までの距離 [mm]

→ **実際のコースに合わせて設定**

---

#### ② 速度の閾値

```cpp
SPEED_THRESHOLD_CM_S = 5;
```

* 到着時間を計算する際の速度閾値 [cm/s]
* 速度が小さい場合の扱いに関係する

---

#### ③ PIDゲイン

```cpp
PID_KP_DEFAULT = 0.0F;
PID_KI_DEFAULT = 0.0F;
PID_KD_DEFAULT = 0.0F;
```

* 前回の「車両走行実験」で決定した値を設定
* **必要に応じて調整**

---

#### ④ 交差時間のマージン

```cpp
TIME_MARGIN_US = 500000;
```

* 交差点での衝突回避判定に用いる時間的な余裕 [μs]
* 必要に応じて実験条件に合わせて調整

### 設定のポイント

> **コースに合わせて距離を設定し，前回実験で得たPIDゲインを使用する**

---

# 2. モニタの説明

### `exp3_monitor.py` を使用

1. モニタを起動

```text
python/exp3_monitor.py
```
2. COMPORTでマイコンの接続ポートを選択し，Connectを押してシリアル通信を開始する．
3. 実験車両のバッテリを接続し，電源を入れる．
4. 実験車両をコースに設置する．
5. `collision_flag` をONにしてSTARTを押し，計測を開始する．
6. 車両が衝突することを確認し，FINISHを送信して計測を終了する．
7. `collision_flag` をOFFにしてSTARTを押し，計測を開始する．
8. 車両が衝突を回避することを確認し，FINISHを送信して計測を終了する．
9. 計測終了後，Disconnectを押してシリアル通信を終了する．

### 実験の流れ

```text
コース・パラメータ設定
        ↓
      Connect
        ↓
  collision_flag = OFF
        ↓
       START
        ↓
    2台を走行
        ↓
  衝突回避を確認
        ↓
      FINISH
        ↓
     ログ確認
        ↓
    Disconnect
```

### 確認すること

* 2台の車両が交差点へ進入する
* 車両同士が衝突結果
* 設定した条件で適切に回避できている
* ネゴシエーションの評価
