## スライド2｜車車間通信

### タイトル
V2IからV2Vへ

### 背景
- 自動運転では、交差点や合流部での衝突回避が重要
- 車両の位置や速度などの情報を利用して衝突を回避する方法が研究されている

### V2I（Vehicle to Infrastructure）
- インフラ側のセンサで車両を検知
- 基地局などを経由して車両へ情報を送信
- センサ・基地局などの設備が必要
- 設置・維持コストが課題

### V2V（Vehicle to Vehicle）
- 車両同士が直接情報を交換
- 外部のセンサや基地局を必要としない
- 本実験ではV2V通信を利用する

### 比較図
```text
V2I
車両A → インフラセンサ → 基地局 → 車両B

V2V
車両A ←──── 直接通信 ────→ 車両B
```

### 重要メッセージ
> 本実験では、V2V通信による車両同士の情報交換を利用して衝突回避を実現する。

## スライド3｜実験システム

### タイトル
実験システムの全体構成

### このスライドで伝えること
- 車両ごとにマイコンを搭載する
- 車両同士はESP-NOWで無線通信する
- 各車両の速度を制御し、衝突回避を行う

### 全体構成
```text
                 ESP-NOW
        ┌─────────────────────┐
        ↓                     ↓
   ┌─────────┐           ┌─────────┐
   │ 車両A    │           │ 車両B    │
   │ ESP32    │←────────→│ ESP32    │
   │          │           │          │
   │ 速度制御 │           │ 速度制御 │
   │ (PID)    │           │ (PID)    │
   │    ↓     │           │    ↓     │
   │  モータ  │           │  モータ  │
   └─────────┘           └─────────┘
        ↓                     ↓
      走行                   走行
        └────→ 衝突回避 ←────┘
```

### システムの主要要素
- **ESP32**：車両の制御・通信を担当
- **ESP-NOW**：車両間の無線通信
- **PID制御**：車両の速度を目標値に制御
- **衝突回避制御**：車両間の情報を利用して速度・走行タイミングを調整

- 実験システムの全体構成図を大きく掲載
- 各要素の役割を簡単に補足

## スライド4｜ESP-NOW

### タイトル
車両間通信：ESP-NOW

### ESP-NOWとは
- ESP32などのデバイス間で利用できる無線通信方式
- Wi-Fiのようにアクセスポイントを介さず、デバイス同士で通信できる
- 本実験では車両同士の情報交換に利用する

### 本実験で利用する情報
- 車両の走行状態
- 交差点までの到達予測時間
- 衝突回避制御に必要な情報

### 通信イメージ
```text
       ESP-NOW
┌─────────────────┐
│                 │
↓                 ↓
ESP32 A  ←────→  ESP32 B
  │                 │
車両A               車両B
```

### この回での扱い
- 今回はESP-NOWの概要と利用目的を理解する
- 詳細な通信方法・プログラムについては第2回で扱う

### 重要メッセージ
> ESP-NOWを使って、車両同士が衝突回避に必要な情報を直接交換する。

## スライド6｜衝突回避制御

### タイトル
車車間通信を利用した衝突回避制御

### 基本アイデア
- 2台の車両が交差点へ向かって走行する
- 各車両が「交差点へ到達するまでの残り時間」を計算する
- その情報をESP-NOWで相手車両へ送信する
- お互いの到達タイミングを比較する
- 必要に応じて速度を変更し、交差点への進入タイミングを調整する

### 制御イメージ
```text
        車両A
          ↓
          ↓
      ┌───────┐
      │       │
─────→│ 交差点 │←─────
      │       │
      └───────┘
          ↑
          ↑
        車両B

車両A：あと○秒で交差点
       ↓ ESP-NOW
車両B：あと△秒で交差点
       ↓
到達タイミングを比較
       ↓
速度を調整
       ↓
衝突を回避
```

### 制御のポイント
- 重要なのは「車両の位置」だけではなく「いつ交差点へ到達するか」
- 車両同士が情報を共有することで、走行タイミングを調整する

### 重要メッセージ
> 車両同士で到達予測時間を共有し、交差点への進入タイミングを調整することで衝突を回避する。
